How networks work

A network is a capacity pool. Assign each of a channel's sources to one, and set max streams to the number of simultaneous connections that upstream permits.

  • A slot is one upstream connection, not one viewer. Ten people watching the same channel use one slot.
  • When every source for a channel is on a full network, the request is refused with 503 instead of being queued.
  • A source with no network set is uncapped.
  • Lowering a limit never evicts current streams; it applies to the next one.

If a channel has sources on different networks, it automatically uses whichever one has room — highest priority first.

How profiles are applied

A request for /stream/<id>?profile=<profile-id> pipes the channel's source output through:

ffmpeg -hide_banner -nostdin -loglevel <level> <input args> -i pipe:0 <output args> -f <container> pipe:1

Without ?profile= the source output is passed through untouched. Each (channel, profile) pair gets its own shared session, so ten viewers of the same channel and profile cost one upstream connection and one encode.
